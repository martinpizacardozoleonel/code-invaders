    Etiquetas y Funciones JavaScript

    Función/Palabra clave Descripción Ejemplo
    function() Declaración de función function suma(a, b) { return a + b; }
    const Variable constante (no cambia) const x = 10;
    let Variable mutable let x = 10; x = 20;
    => (flecha) Función flecha moderna (x) => x + 1
    console.log() Mostrar en la consola console.log("Hola");
    addEventListener Escuchar eventos element.addEventListener('click', fn)
    querySelector Seleccionar elemento CSS document.querySelector('.clase')
    map() Transformar array [1,2,3].map(x => x * 2)
    filter() Filtrar array [1,2,3].filter(x => x > 1)
    Promise Operaciones asíncronas new Promise(resolve => {})
    async Función asíncrona async function obtenerDatos() {}
    await Esperar promesa const data = await fetch('/api')
